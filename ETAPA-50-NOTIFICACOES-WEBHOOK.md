# Etapa 50 — Notificações de falhas e backups atrasados

Implementa notificações operacionais por webhook HTTP para as ações executadas por `scripts/run-and-record.sh`. A notificação é enviada após o registro no CSV e no arquivo de status. Falhas são notificadas por padrão; sucessos são opcionais. Consulte `README-ETAPA-50.md` para configuração e limitações.
