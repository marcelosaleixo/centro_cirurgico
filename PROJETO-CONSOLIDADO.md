# Consolidação do projeto

Contém os módulos de RH (colaboradores, escalas, férias, feriados, banco de horas, trocas, equipes e funções), estoque e movimentações, carrinhos/armários, salas cirúrgicas, autenticação e gestão de usuários, auditoria, dashboard, fechamento mensal do RH, layout modular responsivo e migrations Flyway até V15.

As permissões continuam aplicadas no servidor pela configuração de segurança. O menu lateral é navegação visual e não substitui autorização.
